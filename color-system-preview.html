04 / Text Hierarchy

Typographic Color Scale

SECTION LABEL

Heading — Deep Black #111111

Primary text — The main body content uses Deep Black on warm backgrounds. This provides 13.2:1 contrast ratio on Soft Cream, exceeding WCAG AAA requirements.

Secondary text — Supporting descriptions and explanations use a slightly lighter tone. Still highly readable at 7.1:1 contrast.

Muted text — Timestamps, footnotes, and placeholders. 3.8:1 contrast (large text AA compliant only).

Interactive link — Electric Blue #2563EB

07 / Border Colors

Warm Borders for Warm Surfaces

Token Color Hex Usage
Border Default #E8E2D6 Standard card/section borders
Border Light #EDE8DD Subtle dividers within sections
Border Subtle rgba(0,0,0,0.06) Nearly invisible card borders
Border Focus #2563EB Input focus borders
Border Premium #5E1223 Premium card left accent
Border Hover #D4CFC5 Hover state on bordered elements

Key Principle: Borders are NOT cool gray (#E2E8F0). They are warm-tinted to match the cream/ivory palette. This is the Notion approach — borders should feel like they belong to the warm surface, not like cold metal dividers.
